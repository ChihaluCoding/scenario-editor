# Scenario Editor

公開版: https://chihalucoding.github.io/scenario-editor/

ノベルゲーム／アドベンチャーゲーム向けのシナリオ作成 Web アプリ。

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/ に静的サイトを出力（そのままホスティング可）
npm test        # ロジックのユニットテスト（Vitest）
```

## 技術構成

| 領域       | 採用                                            |
| ---------- | ----------------------------------------------- |
| 基盤       | React 19 + TypeScript + Vite                    |
| 状態管理   | zustand + immer（Undo/Redo・自動保存）          |
| 永続化     | IndexedDB (`idb`)：複数プロジェクト・アセット・自動バックアップ |
| スキーマ   | zod（インポート検証・マイグレーション）         |
| スタイル   | Tailwind CSS v4                                 |
| ノード図   | React Flow (`@xyflow/react`)                    |
| 並べ替え   | dnd-kit                                         |
| アイコン   | lucide-react                                    |
| テスト     | Vitest                                          |

## 機能

### 執筆

- **台本エディタ** — セリフ／地の文／選択肢／ジャンプ／**変数操作**／メモの6種類の行。ドラッグで並べ替え
- **キャラクター管理** — 名前・テーマカラー・立ち絵・設定メモ
- **フロー図** — シーンの分岐をノードグラフで可視化（条件付き遷移は破線）。ドラッグで自由配置
- **全文検索・一括置換** — 台本・シーン・キャラクター・変数を横断検索。絞り込み、結果への移動、Undo可能な一括置換
- **表示テーマ** — ホワイトモードを標準採用。ヘッダーからダークモードへ切り替え可能
- **制作管理** — チャプター・タグ・制作状態でシーンを整理し、完成率を表示
- **シーンテンプレート** — 複数行の構成を保存して、ID重複なしで再利用
- **TODO・ブックマーク** — 台本行に要修正メモや目印を付け、制作パネルから移動
- **キャラクター分析** — セリフ数・文字数・登場シーン・長文・語尾の連続を集計
- **演出コマンド** — 背景、BGM、効果音、立ち絵表示、画面効果、待機を台本内で制御
- **立ち絵・表情差分** — キャラクターごとに複数登録し、セリフ／演出行から左・中央・右へ表示
- **プレビューデバッグ** — 変数の直接編集・プリセット・セッションセーブ・直前の選択肢への巻き戻し
- **アセットライブラリ** — 素材検索、タグ、全プロジェクトの使用箇所、未使用、重複候補を管理

### 変数・条件分岐

- **変数** は数値（好感度・スコア）／フラグ（ON・OFF）／文字列の3種類
- **すべての行に実行条件**を付けられる。満たさない行は再生時にスキップされる
- **選択肢ごと**に出現条件（非表示 or 選択不可）と、選んだときの変数変化を設定できる
- **自動ルートテスト** — 選択肢と変数状態を仮想実行し、到達率・循環・行き止まり・矛盾条件を検出
- **エンディング管理** — NORMAL／GOOD／BAD／TRUE ENDを登録し、到達手順を一覧表示
- ジャンプ行に条件を付ければ**条件付きルート分岐**になる
- プレビュー中に変数の現在値をリアルタイム表示（デバッグ用）

### データ

- **複数プロジェクト** — ヘッダ左のメニューで切り替え・複製・削除
- **自動バックアップ** — 数分おきにスナップショットを保存し、いつでも復元可能
- **アセット管理** — 背景・立ち絵・BGM をドラッグ＆ドロップで取り込み、IndexedDB に保存（1ファイル 8MB まで）
- **書き出し** — プロジェクト JSON（画像・音声を data URL で同梱）／台本 Markdown／エンジン用フラット JSON
- **エンジン別書き出し** — Ren'Py／ティラノスクリプト／Godot JSON／Unity C#／ボイス収録CSV
- **自動チェック** — 到達不能シーン、遷移先未設定、削除済み変数の参照、全選択肢が条件付きで詰む可能性、など

## ショートカット

| キー                      | 動作               |
| ------------------------- | ------------------ |
| `Ctrl+Z`                  | 元に戻す           |
| `Ctrl+Shift+Z` / `Ctrl+Y` | やり直し           |
| `Ctrl+Enter`              | プレビュー開始     |
| `Ctrl+F`                  | 全文検索・置換     |
| `Space` / `Enter`         | プレビューを進める |
| `Esc`                     | プレビューを閉じる |

## 設計メモ

- `src/types.ts` の zod スキーマが唯一の定義元。型はすべてここから導出する
- `src/lib/vars.ts` は条件評価と変数更新の純粋関数。`src/lib/analysis.ts` は遷移グラフと問題検出。
  どちらも副作用がなく、`*.test.ts` でテスト済み
- `src/lib/db.ts` が IndexedDB の唯一の入口。画像・音声は `asset:<id>` 形式で参照し、
  `src/lib/assets.ts` が object URL に解決してキャッシュする
- 書き出した `*.engine.json` は `{ op: 'say' | 'text' | 'jump' | 'set' | 'choice' }` のフラットな
  コマンド列（条件は `when` フィールド）なので、自作エンジンからそのまま読み込めます

`legacy/` には最初に作ったビルド不要版（Vanilla JS）を残してあります。
