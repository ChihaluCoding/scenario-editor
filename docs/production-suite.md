# 制作支援スイート 仕様

## 目的

長編・分岐型シナリオを、構成整理、再利用、執筆管理、自動検証まで1つのアプリで完結できるようにする。

## スコープ

### 自動ルートテスト

- 初期変数から選択肢・条件・変数操作・ジャンプを仮想実行する
- シーン／行の到達率、エンディング到達ルート、行き止まり、循環、成立不能条件を表示する
- 状態数に上限を設け、巨大な分岐でもブラウザーを停止させない

### チャプター・タグ・進捗

- シーンへチャプター、複数タグ、制作状態を設定する
- シーン一覧をチャプター単位で折りたたむ
- チャプター・制作状態で絞り込む
- 完成シーンの割合を表示する

### シーンテンプレート

- 現在のシーンに含まれる複数行を名前付きテンプレートとして保存する
- テンプレートを任意のシーン末尾へ追加する
- 適用時に行、選択肢、条件、効果のIDを再生成する
- 不要なテンプレートを削除する

### TODO・ブックマーク

- 台本行へTODO文とブックマークを設定する
- 右側の制作パネルへ一覧表示し、該当行へ移動する

### キャラクター分析

- キャラクターごとのセリフ数、文字数、登場シーン数を表示する
- 120字を超えるセリフと、同じ語尾の連続を集計する

### エンディング管理

- シーンを NORMAL／GOOD／BAD／TRUE エンドとして設定する
- エンディング一覧と自動テストで見つかった到達手順を表示する
- エンディングシーンの末尾でプレビューを終了する

## 受け入れ条件

1. 既存プロジェクトを読み込むと、新規フィールドが安全な初期値で補完される。
2. 制作管理項目とテンプレートは自動保存・Undo／Redoの対象になる。
3. テンプレート適用後にIDが重複しない。
4. 自動ルートテストは循環シナリオでも有限時間で終了する。
5. TODO、ブックマーク、検証結果から該当台本行へ移動できる。
6. 書き出しJSONへ新しいシーンメタデータが含まれる。
7. 外部API・サーバー・課金サービスを追加しない。

## 非対象

- 複数ユーザーのリアルタイム共同編集
- AIによる文章生成・校正
- 数学的に完全な制約充足証明
- テンプレートのプロジェクト間共有
