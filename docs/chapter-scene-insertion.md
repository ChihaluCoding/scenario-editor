# チャプター内へのシーン追加

## スコープ

- チャプター見出しから、そのチャプターへ新しいシーンを追加できるようにする。
- シーン一覧上部の追加ボタンは、現在選択中のシーンと同じチャプターへ追加する。
- 新しいシーンは対象チャプターの末尾へ挿入し、そのまま選択する。

## 制約

- 既存シーンのチャプター値と並び順は変更しない。
- チャプターごとの折りたたみ、フィルター、ドラッグ並べ替えを維持する。
- サーバーや有料サービスは追加せず、GitHub Pages向け静的ビルドを維持する。

## 受け入れ条件

- 同じチャプターへ複数のシーンを追加できる。
- チャプター見出しの件数が追加直後に増える。
- 選択中のシーンが見つからない場合は「未分類」へ安全に追加できる。
- lint、単体テスト、本番ビルドが成功する。

## 非対象

- 複数チャプターへの同時所属。
- チャプターそのものの並べ替え。
- シーンの複数選択・一括移動。
