# 全文検索・一括置換 仕様

## 目的

長編シナリオ内の文言を横断的に探し、該当箇所へ移動または一括置換できるようにする。

## スコープ

- プロジェクト名・著者名
- シーン名・あらすじ／演出メモ
- セリフ・地の文・制作メモ・選択肢の質問文／各項目・ボイスファイル名
- キャラクター名・設定メモ
- 変数名・メモ
- 対象種別、シーン、行の種類、話者による絞り込み
- 大文字と小文字を区別する検索
- 検索結果からシーン／台本行への移動
- 現在の絞り込み結果に対する一括置換（1回の Undo で取り消し可能）
- `Ctrl+F` / `Cmd+F` で検索画面を開く

## 受け入れ条件

1. 空の検索語では検索・置換を実行しない。
2. 初期状態では大文字と小文字を区別せず検索する。
3. 結果には対象、所属シーン、該当回数が表示される。
4. 台本行の結果を選ぶと台本タブへ移動し、対象行が画面内に表示される。
5. 一括置換は現在の絞り込み条件に一致した項目だけを変更する。
6. 一括置換後に Undo すると変更前のプロジェクトへ戻せる。
7. 静的ビルドのみで動作し、外部APIやサーバーを必要としない。

## 非対象

- 正規表現検索
- アセットファイルの内容検索
- 条件式や内部IDの置換
- 複数プロジェクトをまたぐ検索
