# フローからのシーン詳細表示

## スコープ

- フロー画面のシーンカードをダブルクリックすると、そのカード自体を詳細表示へ展開する。
- 1回クリックは従来どおりシーン選択として扱う。

## 制約

- シーン位置のドラッグ操作と競合させない。
- 静的ビルドと既存のプロジェクトデータ形式を維持する。

## 受け入れ条件

- カードをダブルクリックすると対象シーンのカード内に詳細が表示される。
- フローの表示タブ、位置、ズームを維持する。
- あらすじ、制作状態、タグ、背景・BGM設定、台本行の内容を確認できる。
- カードにダブルクリック操作の案内がある。
- 展開中のカードをもう一度ダブルクリックすると通常表示へ戻る。

## 非対象

- モーダルや別画面を開くこと。
- シーンカードのデータ項目やレイアウトの全面変更。
