# ホワイトモード 仕様

## 目的

編集画面を白基調に変更し、長時間の執筆でも文字・境界・操作対象を見分けやすくする。

## スコープ

- ホワイトモードを初期テーマにする
- ヘッダーからホワイト／ダークを切り替えられるようにする
- 選択したテーマをブラウザーへ保存する
- 入力欄、モーダル、サイドバー、フロー図の配色を各テーマへ対応させる
- ゲームプレビューは背景演出と可読性を守るため、従来の暗い配色を維持する

## 受け入れ条件

1. 初回起動時は白い編集画面が表示される。
2. 主要テキストと補助テキストが白背景上で判読できる。
3. ヘッダーのボタンでテーマを切り替えられる。
4. 再読み込み後も選択したテーマが復元される。
5. フロー図のノード、ラベル、接続線が両テーマで判読できる。
6. プレビュー画面の暗い表示はテーマ切替の影響を受けない。
7. 外部APIやサーバーを追加せず、静的ビルドで動作する。

## 非対象

- OS設定との自動同期
- プロジェクトごとのテーマ保存
- ユーザーによる任意色の編集
