# 行間への台本行追加

## スコープ

- 各台本行の操作メニューから、その行の直前または直後へ任意種類の行を追加できるようにする。
- 追加後は新しい行までスクロールし、主要入力欄へフォーカスを移す。
- 既存の `Ctrl/Cmd + Enter` は、同じ種類の行を直後へ追加する操作として維持する。

## 制約

- 既存の Undo、自動保存、並べ替え処理をそのまま利用する。
- 日本語ラベルは「この行の上に追加」「この行の下に追加」で統一する。
- 320px 幅でもメニューを操作でき、ボタンラベルを折り返さない。
- サーバーや有料サービスは追加せず、静的ビルドを維持する。

## 受け入れ条件

- 先頭行の上、途中行の上・下、末尾行の下へ追加できる。
- セリフ、地の文、選択肢、ジャンプ、変数操作、メモ、演出を選択できる。
- 不正な行位置では追加処理を行わない。
- lint、単体テスト、本番ビルドが成功する。

## 非対象

- 複数行の一括挿入。
- 行テンプレートの挿入。
- キーボードショートカットの追加。
