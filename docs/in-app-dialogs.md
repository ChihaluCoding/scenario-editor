# アプリ内ダイアログ統一仕様

## スコープ

- 削除や一括置換の確認を、ブラウザ標準の確認ダイアログではなくアプリ内モーダルで表示する。
- 変数プリセット名の入力を、ブラウザ標準の入力ダイアログではなくアプリ内モーダルで表示する。
- ライト・ダーク両テーマで既存UIと同じ配色を使う。

## 制約

- 静的ビルドのまま動作し、外部サービスやサーバーを追加しない。
- `Escape` キーと背景クリックはキャンセルとして扱う。
- 確認前にデータを変更しない。

## 受け入れ条件

- `window.confirm`、`window.prompt`、`window.alert` をアプリのソースコードで使用しない。
- 削除操作には対象と影響を明記し、「削除」「キャンセル」を表示する。
- 一括置換とプリセット保存にも用途に合った確認ボタンを表示する。
- キーボード操作時に主要な入力欄または実行ボタンへフォーカスする。

## 非対象

- トースト通知のデザイン変更。
- 各削除処理のデータ仕様変更。
