# 選択肢テキスト入力の不具合修正

## スコープ

- 台本編集画面にある選択肢のテキスト入力欄を修正する。
- 1文字目の入力後もフォーカスと入力内容を保ち、続けて複数文字を入力できるようにする。
- 原因に対応した回帰テストを追加する。

## 制約

- 既存プロジェクトデータの形式は変更しない。
- 選択肢の追加、削除、遷移先設定、Undo/Redo の既存動作を維持する。
- 静的ビルドと GitHub Pages 互換性を維持する。

## 受け入れ条件

1. 空の選択肢入力欄へ日本語または英数字を2文字以上連続入力できる。
2. 入力中に対象欄からフォーカスが外れない。
3. 入力した全文がプロジェクト状態へ保存される。
4. テスト、Lint、型検査を含むビルドが成功する。

## 非対象

- 選択肢UIのデザイン変更。
- プロジェクト保存形式の更新。
- 選択肢以外の編集機能の仕様変更。
